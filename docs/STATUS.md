## v0.4：网站连接本机采集助手（本机已验收，待发布）

- 首次安装 Windows x64 助手并配对，以后访问同一网站自动重连自己的电脑；不需要 Java / Node / Maven 或运行命令。首次设置与浏览器本地网络权限仍必要，不能无授权扫描电脑。网站沿用现有 GitHub Pages 域名，自定义域名须配置精确来源。
- 独立 `/bridge/`：Spring 标准 CORS 精确来源 / 方法 / 请求头 / PNA 预检；8 位随机码、5 分钟有效、一次使用、每分钟最多 5 次尝试；256 位浏览器令牌按来源绑定，SQLite 只存哈希，网站和本机管理可撤销。旧 `/api/` 不开放跨站读取，所有入口仍仅回环 Host、no-store 和禁 iframe。
- 后端每 5 秒检查日志 / Skills 元数据，变化时重扫，每 60 秒强制重扫；前端按新成功采集时间自动刷新，保留筛选，隐藏页面暂停轮询。切演示 / 公开快照取消旧请求与自动读取，断线明确保留旧数据，401 清除失效凭据。采集失败不替换原统计，正在生成中的 Token 不保证即时出现。
- 原生 jpackage EXE 启动器、系统托盘、当前用户独立数据目录、重复启动锁、用户可选登录启动；自带 Temurin 21.0.13+9 JRE，保留 LICENSE / NOTICE / legal。Windows 安装器与便携包构建采用固定 WiX 3.14.1，脚本拒绝覆写已有产物，不携带本机数据。
- 新手工 Windows Actions 只生成并上传 EXE / ZIP / SHA256SUMS，不自动创建 Release。产物尚无代码签名，也未在其他电脑或各浏览器验收；macOS / Linux 的免命令安装器暂未提供。使用与开发者打包入口见 [采集助手说明](ASSISTANT.md)。

## 简要维护记录

- **新旧计数重复**：Codex 同时记录请求用量和累计用量。不能将两种来源直接相加。以响应身份为主，匹配累计快照抑制重复，回归覆盖混合格式。
- **Vite public 导入**：直接从 `public/` 导入 JSON 不符合开发服务器的资源规则。虚构数据迁入 `src/demo.json`，保持开发和生产行为一致。
- **图标包迁移**：registry 已将 `lucide-vue-next` 标为弃用，改用官方 `@lucide/vue` 并锁定依赖。
- **依赖安装后开发缓存**：替换包时已运行的 Vite 会持有旧依赖缓存。安装完成后重启并强制预构建，浏览器刷新后验证。
- **时区输入**：不可信快照中的任意时区会使日期格式化报错；导入契约加入 Intl 时区检查。
- **本地字体**：改为随站点构建的 Fontsource 字体，不依赖 Google Fonts 远程请求。
- **模板处理器格式化**：多语句内联点击处理器在无分号格式化后无法编译；提取为具名函数，生产构建作为最终验证。
- **构建提示**：ECharts 图表块约 559 KB（gzip 约 191 KB），有体积提示；Zod 的注释注解被 Rollup 忽略。构建成功，后续可按实际性能证据进一步拆分。
