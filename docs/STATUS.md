## 简要维护记录

- **新旧计数重复**：Codex 同时记录请求用量和累计用量。不能将两种来源直接相加。以响应身份为主，匹配累计快照抑制重复，回归覆盖混合格式。
- **Vite public 导入**：直接从 `public/` 导入 JSON 不符合开发服务器的资源规则。虚构数据迁入 `src/demo.json`，保持开发和生产行为一致。
- **图标包迁移**：registry 已将 `lucide-vue-next` 标为弃用，改用官方 `@lucide/vue` 并锁定依赖。
- **依赖安装后开发缓存**：替换包时已运行的 Vite 会持有旧依赖缓存。安装完成后重启并强制预构建，浏览器刷新后验证。
- **时区输入**：不可信快照中的任意时区会使日期格式化报错；导入契约加入 Intl 时区检查。
- **本地字体**：改为随站点构建的 Fontsource 字体，不依赖 Google Fonts 远程请求。
- **模板处理器格式化**：多语句内联点击处理器在无分号格式化后无法编译；提取为具名函数，生产构建作为最终验证。
- **构建提示**：ECharts 图表块约 559 KB（gzip 约 191 KB），有体积提示；Zod 的注释注解被 Rollup 忽略。构建成功，后续可按实际性能证据进一步拆分。
- **首次 Pages 部署 404**：第一次 Actions 部署早于仓库启用 Pages，发布步骤返回 Not Found。通过仓库 API 启用 workflow 类型 Pages 后重试失败任务，部署成功；公开页面与浏览器资源加载已验证。
- **Claude 输入口径**：其 `input_tokens` 不含缓存读/写，不能直接套用 Codex 输入口径；归一化时加读写，缓存命中仅取读，测试覆盖顶层及分级缓存写字段。
- **响应流片段**：同一 Claude message/request 后续片段重复累计用量；按各项最大值合并而非逐条累加，复制的子代理日志同样去重。
- **浏览器对象克隆**：Vue 响应式对象不能直接 structuredClone；编辑先 toRaw，持久化先 Zod 白名单解析，已用真实页面编辑验证。
- **JAR 重打包权限**：沙箱内测试通过但 repackage 重命名失败；授权后只执行跳过已通过测试的 package 成功，未将打包失败当作测试失败重复测试。
